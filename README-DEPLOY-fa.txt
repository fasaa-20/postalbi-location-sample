بستهٔ آزمایشی PostalBI — اطلاعات مکانی

این بسته فقط داده‌های ساختگیِ همراه برنامه را نمایش می‌دهد. به SSAS، SQL Server یا API وصل نمی‌شود. اعداد آن آمار عملیاتی شرکت ملی پست نیستند. برچسب روی داشبورد طبق درخواست حذف شده است؛ این توضیح را کنار بسته نگه دارید.

محتوا: صفحهٔ «پیشرفت» و پنج زیرصفحهٔ «ژئوکد»، «پلاک»، «نقشه»، «معابر»، «اطلس». سایر بخش‌های منو پیام «در دست طراحی» نشان می‌دهند.

راه‌اندازی روی IIS / Windows Server:
1. ZIP را باز کنید و همهٔ فایل‌ها (index.html، پوشهٔ assets و همین راهنما) را در پوشهٔ ریشهٔ یک IIS Site با Static Content نصب‌شده کپی کنید.
2. Physical Path همان پوشه باشد. برای این نسخه به Python، Node.js، SQL Server، SSAS، URL Rewrite یا تنظیم connection string نیاز نیست.
3. آدرس ریشهٔ سایت را در مرورگر باز کنید. برنامه به /#/dev/location می‌رود. مسیرها بعد از # هستند و با Refresh باقی می‌مانند.
4. اگر برنامه زیر Virtual Directory نصب شده است، آدرس index.html آن پوشه را باز کنید؛ فایل‌های assets با مسیر نسبی بارگذاری می‌شوند.

این نسخه ورود کاربر و کنترل دسترسی ندارد؛ برای استفادهٔ آزمایشی در محیط داخلی مناسب است. برای اتصال به دیتاست SSAS و احراز هویت، نسخهٔ عملیاتی FastAPI جداگانه باید منتشر و تنظیم شود.
